# Contribuindo com o Archon

Contribuições são bem-vindas! Para colaborar com o projeto:

1. Faça um **fork** deste repositório.
2. Crie uma branch para sua alteração: `git checkout -b feat/nova-funcionalidade`.
3. Implemente suas mudanças mantendo a cobertura de testes em `tests/`.
4. Execute a suíte de testes: `pytest -v`.
5. Envie um **Pull Request** descrevendo claramente o problema resolvido e a abordagem escolhida.
